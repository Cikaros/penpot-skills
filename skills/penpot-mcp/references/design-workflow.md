# 设计工作流与简报模板

## 目录
1. 开场必须问清的四件事
2. 简报模板（结构化）

4. 设计转代码

## 1. 开场必须问清的四件事

1. **对象**：改哪个文件、哪个页面、哪个画板？给出 id 或让用户选中（`penpot.selection`）。
2. **约束**：只准用哪些 token / 组件 / 字体？有没有必须保持不动的区域？
3. **验收**：以什么为准（截图、token 表、栅格、无障碍对比度）？
4. **禁区**：哪些东西绝对不能改（导航结构、品牌色、间距体系）？

缺任何一项就先问，不要用"合理默认值"填空。

## 2. 简报模板

```text
Context: 产品=?? 用户=?? 当前页面=?? 目标画板=??
Goal: 本次要解决的一个具体问题（例：提升表单视觉层级）
Inputs: 现有组件/颜色/字体 token、参考图（说明看哪一部分）
Constraints: 仅用现有组件；WCAG AA；不自创颜色；不改导航
Quality: 全部元素在 390×844 画板内；字号层级 3 档；导出图目视通过
Non-goals: 不做品牌改造、不改交互流程
```

把这段放进 `storage.brief`，后续每步改动都对照它，避免跑偏。

## 3. 十条约束（可执行版）

1. **角色要有边界**："资深产品设计师，懂设计系统与 WCAG；无数据时不替用户做业务决策"，不要写"有创意的设计师"。
2. **结构化而非散文**：按上面的简报模板给信息。
3. **图要指方向**："图 1 只看标签与输入框的留白，其余忽略"——不说清楚，模型会平均用力。
4. **喂规则而非链接**：颜色只用 `/core/colors`，字号不越级，组件用变体不复制。
5. **要变换，不要"成品"**：说"提升层级、去边框、按 token 归一键距"，不要说"重做得现代一点"。
6. **设计转代码要说栈**：框架、样式方案、禁魔数、token 映射到 CSS 变量。
7. **要理由**：每次改动说明取舍与被放弃的方案。
8. **迭代**：分析 → 提案 → 反馈 → 落地，不要 one-shot 全量重画。
9. **给负向约束**："不加新导航模式""不动视觉识别""不假设业务规则"。
10. **利用 Penpot 的结构优势**：token、SVG、开放格式都可被精确读取，优先读结构而不是靠截图猜。

## 4. 设计转代码

```js
// 先拿结构，再生成代码
const css = penpot.generateStyle(penpot.selection, { type: "css", includeChildren: true });
const markup = penpot.generateMarkup(penpot.selection, { type: "html" }); // 视版本支持
```

- 明确输出目标：React/Vue/纯 HTML；Tailwind/CSS 变量。
- 颜色、字号、间距必须映射回 token 名，不要输出 `#3b82f6` 这类魔数。
- 不发明断点；断点来自设计文件里已有的 board 宽度。
- 生成后回填检查：代码里的间距值应能在 token 表里找到。

## 5. 迭代节奏与验收

多屏原型（底部导航、次级页、状态页、可点击流程）在开始前先做屏幕清单与可达性图，具体方法与验收见 [`screen-kit.md`](screen-kit.md)。

**一轮 = 一个可回滚的改动集**

1. 读结构（`shapeStructure`，深度 2–3 足够）。
2. 只改一类：位置 / 排版 / 颜色 / 图片。
3. 立即验收：
   - 几何：`analyzeDescendants(board, (root,s)=> isContainedIn(s,root)?null:s.name)`
   - 视觉：`export_shape(board.id,"png","shape")`
4. 记录：`storage.changes.push({ ids, what, evidence })`。
5. 下一轮前重读一次关键数值，不要假设上一轮结果还在（用户可能手动改过）。

**停止条件**：简报里的 Quality 全部满足，且导出图无回归。不要为了"更精致"继续加改动。

**常见返工原因**（提前避免）：
- 文本没先给宽度（默认 1px），设了 `auto-height` 后被逐字换行；
- 用 `resize` 改文字导致 `growType` 变 fixed；
- 在 flex board 里手改 x/y；
- 追加用了 `appendChild`；
- 图片填充来自错误页字节；
- 跨页查找只搜了当前页（2.18.7 的 `findShapes` 默认反而跨页，仍需显式传根）。
