## V-05 图片上传/读回


```json
{
  "sourceIsPng": true,
  "sourceBytes": 70,
  "media": {"width": 1, "height": 1},
  "dataBytes": 70,
  "dataIsPng": true
}
```

`fillImage.data()` 可 `await`，读回字节仍是 PNG。临时 board 已清理。
