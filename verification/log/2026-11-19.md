## V-05 图片上传/读回

第一次用了一个 CRC 无效的 1×1 PNG，Penpot 返回：

```text
400 invalid-image: ImageMagick ... IDAT: CRC error
```

这说明服务端确实校验图片，不是“上传成功但空白”。

改用 Python `zlib`/`crc32` 生成 CRC 正确的 70 字节 1×1 RGBA PNG 后：

```json
{
  "sourceIsPng": true,
  "sourceBytes": 70,
  "media": {"width": 1, "height": 1},
  "dataBytes": 70,
  "dataIsPng": true
}
```

`fillImage.data()` 可 `await`，读回字节仍是 PNG。临时 board 已清理。
